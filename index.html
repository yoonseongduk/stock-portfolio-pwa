설정 — 시세 조회 API 키

무료 키는 twelvedata.com에서 이메일 가입만으로 발급됩니다.

data.go.kr에서 회원가입 후 "금융위원회_주식시세정보"를 활용신청하면 발급됩니다. 실시간이 아니라 직전 영업일 종가만 제공합니다 (장중 현재가 아님). 두 키 모두 폰 안에만 저장되고, 시세를 조회할 때만 각 서버로 전송됩니다 (보유 종목·거래내역은 전송하지 않음).
